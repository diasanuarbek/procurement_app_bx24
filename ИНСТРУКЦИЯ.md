# Руководство по приложению «Заявки на закупку в Битрикс24»

Приложение разработано для автоматизации подачи заявок в отдел закупа через смарт-процесс Битрикс24.
Сотрудник заполняет перечень необходимых товаров, и **на каждую строку автоматически создается отдельная заявка** в смарт-процессе отдела закупа.

---

## 📌 Ключевые особенности

1. **Ответственный**: автоматически назначается сотрудник, который подает заявку (`ASSIGNED_BY_ID`). В шапке приложения сразу видно, от чьего имени подаются заявки (например, `Заявитель: Иван Иванов`).
2. **Безопасность настроек**: настройки не выводятся в интерфейс для сотрудников. Они зафиксированы в конфигурационном файле `config.js`. Сотрудники не могут ничего сбить или сломать, и не требуется разграничивать права на интерфейс настроек.
3. **Пакетная отправка**: данные отправляются через `BX24 Batch`, даже 50 строк создаются за 1 секунду.
4. **Вставка из Excel**: сотрудники могут скопировать готовую таблицу в Excel (Наименование, Ед. изм., Кол-во, Примечание) и вставить её кнопкой «📋 Вставить из Excel».

---

## ⚙️ Настроенные параметры (Коробочный Битрикс24 компании)

Все настройки зафиксированы в файле `config.js`:
- **Портал**: `b24.alageum.com`
- **ID Смарт-процесса (entityTypeId)**: `1180` (из ссылки `/crm/type/1180/automation/85/`)
- **Воронка / Категория (categoryId)**: `85`
- **Поля смарт-процесса**:
  - Товар: `UF_CRM_53_PRODUCT_NAME` (строка) + системное поле `TITLE`
  - Количество: `UF_CRM_53_QUANTITY` (число)
  - Единица измерения: `UF_CRM_53_UNIT` (список: *штук, метр, кг, км*)
  - Обоснование покупки: `UF_CRM_53_CAUSE` (строка/текст)
  - Файлы / тех. спецификация: `UF_CRM_53_FILES` (множественный файл)
  - Примечание / ссылка: `UF_CRM_53_ADDITIONS` (строка/текст)
  - Заявитель: `UF_CRM_53_1783939121` (привязка к сотруднику, поле ответственный остается стандартным)

## 🏢 Развертывание на коробочном сервере (On-Premise)

Поскольку у вас коробочная версия Битрикс24, вам доступны лучшие условия:

### Шаг 1. Размещение файлов на сервере коробки
Скопируйте папку с приложением (`index.html`, `install.html`, `config.js`, `logo.png`, `css/`, `js/`) прямо на веб-сервер вашего Битрикс24:
- Например, в публичный каталог: `/home/bitrix/www/pub/procurement/`
- Страница станет доступна по внутреннему адресу: `https://b24.alageum.com/pub/procurement/index.html`

*(Также можно разместить на любом внутреннем сервере Nginx / Apache / IIS в вашей локальной сети).*

---

### Шаг 2. Подключение как Локальное приложение в Битрикс24
1. В коробочном Битрикс24 с правами администратора откройте: **«Разработчикам»** ➔ **«Другое»** ➔ **«Локальное приложение»**.
2. Заполните поля:
   - **Название**: `Заявки на закупку`
   - **Использует только API**: Нет (выключено)
   - **URL вашего обработчика**: `https://b24.alageum.com/pub/procurement/index.html`
   - **URL для первоначальной установки**: `https://b24.alageum.com/pub/procurement/install.html`
   - **Права доступа**:
     - `CRM` (`crm`)
     - `Пользователи` (`user`)
3. Нажмите **«Сохранить»**.

---

### Шаг 3. Всё готово к работе!
У всех сотрудников портала в левом меню появится пункт **«Заявки на закупку»**. 
- При открытии система сразу определяет сотрудника как заявителя.
- При заполнении и отправке каждой позиции создается отдельная заявка в смарт-процессе 1180 (воронка 85).
- Файлы, примечания и обоснование автоматически раскладываются по полям `UF_CRM_53_...`.
